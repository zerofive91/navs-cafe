# 네비게이토 카페

명지대학교 네비게이토의 온라인 쉼터입니다. 말없이 함께 머무는 수레바퀴 모양 카페로, 글자 없이 동작만으로 쉬어 갑니다.

## 공간 (수레바퀴의 삶)

| 구역 | 위치 | 동작 |
| --- | --- | --- |
| 중심되신 그리스도 | 가운데, 천창 빛과 나무 | 빛 바라보기, 둥근 벤치에 앉기 |
| 말씀 | 위(북), 서재 | 책 읽기 |
| 기도 | 아래(남), 조용한 방 | 손 모으기 |
| 교제 | 오른쪽(동), 카운터와 큰 테이블 | 주문 → 픽업 → 마시기 |
| 증거 | 왼쪽(서), 입구 라운지 | 문에서 맞이하기 |
| 순종 | 둘레 원형 회랑 | 화분 물주기, 쟁반 반납 |

## 진행 단계

- [x] 1단계 뼈대: 원형 카페 평면, 눌러서 걷기·앉기, 구역별 동작
- [ ] 2단계 그림·캐릭터: 배경·가구·캐릭터 그림, 낮/노을/밤 조명
- [ ] 3단계 활동: 메뉴 고르기, 간식, 상주 캐릭터(사장님·직원), 소리
- [x] 4단계 함께 있기: Supabase Realtime으로 다른 사람 보이기 (아래 세 가지 모드)
- [ ] 5단계 테스트·공개

## 들어가는 방법 (함께 있기)

입구에서 셋 중 하나를 고릅니다.

| 모드 | 동작 |
| --- | --- |
| 혼자 | 서버에 연결하지 않고 혼자 둘러봄 |
| 함께 | 랜덤으로 한 카페에 최대 10명. 가득 차면 2호점, 3호점으로 자동 배정 |
| 초대 | 새 초대 링크(`?c=코드`)를 만들어 공유. 링크를 받은 사람끼리만 같은 카페(최대 15명) |

Supabase Realtime(프로젝트 mju-navs-cafe)의 Presence로 인원을 세고 Broadcast로 위치·동작을 주고받습니다(`js/together.js`).
무료 플랜 한도(동시 연결 200, 초당 메시지 100, 월 200만 개)를 넘지 않도록 위치는 걷는 동안에만 몇 초에 한 번, 동작이 바뀔 때만 보냅니다.

## 실행

빌드 과정 없이 정적 파일만으로 동작합니다.

```
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages(main 브랜치 루트)로 공개합니다.
